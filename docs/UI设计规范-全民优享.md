# 全民优享 · UI 设计规范（V0.9 Mock）

方向名：**Utility Charge Arcade**（对齐运营提供的充电/步数兑礼/网赚参考图）。  
拒绝：软粉 AI 卡片墙、字母色块假图标、无厚度扁平胶囊。

## 1. 色彩

| Token | 色值 | 用途 |
|-------|------|------|
| `--yx-blue` | `#2D6BFF` | 蓝场主色、底栏选中、蓝 CTA |
| `--yx-blue-deep` | `#1A4FD4` | 按钮底部厚度、渐变终点 |
| `--yx-sky` | `#9EC4FF → #EEF5FF` | 页面蓝场舞台 |
| `--yx-orange` | `#FF6A00` | 激励/领取主 CTA |
| `--yx-gold` | `#FFBF1A` | 金币、签到圆点 |
| `--yx-green` | `#2BD67B` | 能量填充、步数 |
| `--yx-ink` | `#1A2233` | 主文案 |
| `--yx-mute` | `#6B7A94` | 次文案 |
| `--yx-card` | `#FFFFFF` | 白底任务/货架 sheet |

按钮必须有「厚度」（下偏移色 shadow），像机台实体键。

## 2. 字体与层级

- 品牌/大数字：700–800，40–56rpx  
- 区块标题：750，30–34rpx  
- 正文：400–500，26–28rpx  
- 辅助：22–24rpx，`--yx-mute`

## 3. 圆角与阴影

- 大卡片：28–32rpx  
- 小芯片/标签：12–16rpx  
- 主按钮：999rpx（胶囊）或 24rpx  
- 阴影：`0 12rpx 40rpx rgba(47,107,255,0.12)`（偏蓝柔影）

## 4. 核心组件

1. **能量主体**：居中 3D 感能量罐/电池 + 底座光晕 + 飘浮金币气泡  
2. **7 日签到条**：圆点进度，第 7 天宝箱加大  
3. **任务行**：左 3D 色块图标 + 标题奖励 + 右「去完成/领取」蓝/橙按钮  
4. **热门活动 2×2**：图标 + 短标题，进汉服节/抽奖/商城/邀友  
5. **运营 Banner**：圆角大图，可点  
6. **弹层**：签到成功、得能量、抽奖结果（金币/礼盒视觉，不引导提现红包常态）  
7. **票种卡**：左图文 + 右价格 +「购票」橙按钮  

## 5. 底栏

顺序：首页 · 商城 · **汉服节** · 能量罐 · 我的  
选中色：`--yx-blue`；汉服节可用略大触控区强化居中。

## 6. 动效（最少 2–3 处）

- 能量罐轻浮起  
- 金币气泡上下漂  
- 主 CTA 按下缩放 / 领取成功弹层淡入  

## 7. 文案边界（总纲）

- 用「能量 / 金币积分 / 抽次」，不把「提现话费」做成主路径  
- 大奖限量公示；假库存、强制分享禁止
