> 配套工程：`traffic-cms/`（配置服务）+ `全民优享/`（uni-app 多端）  
> 视觉约束见：`docs/UI设计规范-V2-年轻人审美.md`（怎么好看）  
> **后端库表 / COS / 缓存拉取完整版**：`docs/流量产品-后端API与数据存储方案.md`  
> 本文约束：什么可配、接口长什么样、怎么编译四端

## 1. 原则

- 小程序只保留骨架与玩法交互；**图片 / icon / 栏目名 / 模块名 / 文案 / 跳转** 全部来自 `AppConfig`。
- 配置服务与同袍会文旅库解耦，第一期 JSON 文件存储。
- 禁止配置「提现 / 秒到账 / 话费红包」等主路径文案（服务端校验）。

## 3. HTTP 接口

Base：`http://127.0.0.1:3100`

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/traffic/v1/bootstrap?platform=mp-weixin&channel=` | 小程序启动全量配置 |
| GET | `/api/traffic/v1/config/:pageKey` | 单页 |
| GET | `/api/traffic/v1/admin/config` | 管理端读草稿/已发布 |
| PUT | `/api/traffic/v1/admin/config` | 保存草稿 body=`{config}` |
| POST | `/api/traffic/v1/admin/publish` | 发布（version+1） |
| POST | `/api/traffic/v1/admin/upload` | multipart `file` |

响应统一：`{ code: 0, msg, data }`。`/uploads/*` 静态可访问；bootstrap 会把 `/uploads/...` 转成绝对 URL。

## 4. 管理页

打开 `http://127.0.0.1:3100/admin/`：

1. 改品牌名 / Tab 文案与图标 URL  
2. 改各页 modules JSON（标题、imageUrl、linkKey）  
3. 上传图片 → 复制相对路径粘贴进配置  
4. 保存草稿 → 发布上线  

小程序冷启动拉取新 `version` 即生效。

## 5. 小程序侧

- `全民优享/src/api` 请求 CMS；失败则用 `src/config/fallback.json`
- `src/store/appConfig.js` 持有配置
- `components/modules/*` + `ModuleRenderer` 按 `type` 渲染
- 自定义 tabBar 读 `tabBar[]`
- 玩法数值（能量、签到态）仍走本地 session / 后续业务 API

环境变量（可在 `src/api/request.js` 改）：

```js
const CMS_BASE = 'http://127.0.0.1:3100' // 真机改为局域网 IP 或网关域名
const USE_REMOTE = true
```

## 6. 四端编译

先启动 CMS，再编译小程序：

```bash
cd traffic-cms && npm start

cd 全民优享
npm run dev:mp-weixin     # 微信 · 产物 dist/dev/mp-weixin
npm run dev:mp-toutiao    # 抖音 · dist/dev/mp-toutiao
npm run dev:mp-kuaishou   # 快手 · dist/dev/mp-kuaishou
npm run dev:mp-alipay     # 支付宝 · dist/dev/mp-alipay

npm run build:mp-weixin   # 及 build:mp-toutiao / kuaishou / alipay
```

`manifest.json`：`mp-weixin.appid` 已配置；`mp-toutiao` / `mp-kuaishou` / `mp-alipay` 的 `appid` 按资质填写。

验收：CMS 管理页改 Tab 文案 / 模块标题 / Banner 图 / 跳转 → 发布 → 微信端冷启动可见；关 CMS 时 fallback 仍可预览。
