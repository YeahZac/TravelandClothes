# UI 升级说明 · Charge Arcade（2026-11-05）

## 用户与竞品结论

- **用户**：16–28，碎片时间打开；要低思考成本闭环「做一点 → 看见进度 → 抽/兑/逛/买票」。
- **喜好**：一件说得清的物件（玻璃罐 + 金属币）、等宽数字账本感、模块之间有空气；讨厌彩虹圆盘、字母块图标、蜜桃弹窗。
- **竞品学习**：网赚/步数/养成的「舞台 + 主角物件 + 一颗橙 CTA」语法；不学提现红包主路径。
- **经营约束**：签到、任务、步数、抽次、兑礼、商城、汉服节售票仍在；提现不做主路径。

## 视觉命题

**Charge Arcade（充能机台）**
