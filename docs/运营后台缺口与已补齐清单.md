## 3. 颗粒度：改什么 → 用户看到什么

### 3.1 风控 / 预算熔断

- **后台路径**：侧栏「风控 / 预算熔断」
- **字段**：日/月激励预算(元)、每人日兑上限、每人日抽上限、日实物单上限、超预算自动熔断、是否允许实物抽奖
- **熔断按钮**：立即熔断 / 解除
- **影响**：
  - 服务端 `placeOrder`（非 mall）被拒，返回 `fuseToast` 文案
  - `GET /bootstrap` → `risk.fused`
  - **不影响**商城现金销售（保证变现出口）
- **图片**：无；纯策略

### 3.2 内容 Banner

- **后台路径**：侧栏「内容 Banner」
- **字段**：ID、页面(home/mall)、标题、副标题、**图片 URL（可预览）**、linkKey、tone、排序、上下架
- **同步**：写入草稿 `pages.home|mall.modules[banner_swiper].payload.items`
- **影响页面**：
  - 小程序 **首页** 顶栏轮播
  - 小程序 **商城** 顶栏轮播
- **图片规范**：建议 750×320，上传到 `qmyx/banners/`，把返回 path 填入
- **生效**：保存后 → 规则页「发布上线」→ 前端 version 变更拉取

### 3.3 文案合规

- **ID 约定**：`compliance`（全局脚注）、`footerNote`、`redeemTip`（兑礼页）、`mallTip`、`fuseToast`（熔断提示）
- **影响**：`config.copy.*`；熔断提示进 `risk.fuseToast`

### 3.4 兑礼 SKU

- **字段**：模式(growth/points/…)、积分/能量/邀人/连签/现金分、**成本(元)**、库存、标签、图片、说明
- **影响**：
  - `/pages/gift/list`、`/pages/gift/detail`
  - `/pages/order/confirm` 门槛与扣减
  - 能量罐满兑默认商品 `g1`
- **图片**：礼品主图，展示在详情 cover（无图则字母占位）

### 3.5 兑换履约

- **发货**：物流公司 + 运单号
- **影响**：用户 `/pages/order/detail` 展示承运与单号；后台列表可检索

### 3.6 渠道

- **影响**：用户表 `channel` 分布统计；投放落地页带 `channel=`

## 5. 运营使用口诀

1. **先定预算再开兑**（风控页）  
2. **改 Banner 必看预览图 → 保存 → 发布**  
3. **兑礼成本按「采购+预估运费」填，禁止只填 1688 标价**  
4. **日实物 cap + 熔断** 是默认保险丝  
5. **商城不停、兑礼可停** —— 熔断时仍可卖货回血
