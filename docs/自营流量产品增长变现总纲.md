# 自营流量产品：增长、玩法与变现总纲

> 定位：**公司自营、自掏激励成本的 C 端玩流量产品**  
> 与同袍会 / 景区 / 汉服节等第三方业务**完全独立**  
> 用途：产品需求、后台、接口、数据库、版本研发的唯一行动纲领  
> 版本：V3.0  
> 日期：2026-11-05

---

## 0. 先把话说死

### 0.1 我们是什么

我们自己养用户、自己发奖、自己卖货、自己赚广告和商品差价。

```text
公司花钱买“打开 / 传播 / 停留”
  → 用户每天来玩（签到、步数、偷能量、组队、抽奖）
  → 用户带走低成本礼品 / 产生商城订单 / 看广告
  → 贡献毛利覆盖激励成本后盈利
```

**不是**给汉服节、景区、同袍会做工具或代运营。  
那些品牌/活动若要合作，只是后期广告主或奖池赞助方，**不是产品本体**。

### 0.2 对什么负责

| 指标 | 定义 | 为什么 |
|------|------|--------|
| DAU | 日打开人数 | 流量产品的生命线 |
| 次留 / 7 留 | 回来没有 | 决定激励是否白烧 |
| K 因子 | 有效老带新 | 决定获客能不能自循环 |
| 激励成本占比 | 礼品+运费+积分负债 / 收入 | 决定会不会把自己玩死 |
| 贡献毛利 | 商城毛利+广告净收入+其他 − 激励与履约 | 唯一赚钱标准 |

### 0.3 一句话

> **做一个年轻人每天愿意打开的“任务—进度—抽奖—兑礼—逛街”小程序；公司用低成本好物和游戏化机制买流量，用商城与广告把流量变现。**

## 1. 竞品里真正玩火的东西（要学什么）

### 1.1 对标清单

| 竞品 | 学什么 | 别学什么 |
|------|--------|----------|
| **芭芭农场 / 多多果园** | 养成进度条、真实发货建立信任、每日碎片任务、下单/浏览加速 | 前期不要做成“要几个月才出货”的劝退节奏；首兑要更快 |
| **蚂蚁森林** | 偷能量唤活、好友互动、排行榜、定时收取 | 纯精神奖励留存偏弱，我们要补实物出口 |
| **步数宝类** | 步数变货币、币+邀请/签到/现金的柔性兑礼门槛、限时开兑、夺宝抽奖 | 现金提现易引黑产与合规风险，早期慎做 |
| **拼多多砍一刀** | 差一点点就成功、损失厌恶、社交求助 | 过度压榨社交会透支信任，次数与强度要封顶 |
| **try try / 试用裂变** | 路径极短、支付/领奖后自然分享、利益即时 | 功能别做散，聚焦一条主链路 |
| **微保步数王者** | 步数门槛贴近真实通勤、多出口（抽奖/兑礼/任务）、节日换皮 | 我们没有保险主业，变现出口改成商城+广告 |

### 1.2 年轻人吃的心理机制（设计时必须用上）

1. **差一点点**：进度 90%+、差 1 人、差 20 分  
2. **今天不做就亏**：连续签到、限时礼包、早晚场开兑  
3. **真实拿到手**：第一件礼必须快、真、能晒  
4. **社交不尴尬**：求助文案好玩，不做乞讨感强制分享  
5. **有身份感**：等级、连续天数、队内角色、皮肤  
6. **低思考**：三步内完成今日闭环  

### 1.3 我们要做成的产品气质

面向 16–28 岁：轻游戏感、潮玩感、奖励感，而不是政务/文旅/社团官网感。

视觉与文案可以换主题皮肤（校园、春节、潮流、宠物），但**玩法骨架不变**。

## 2. 产品骨架：一条主闭环 + 四个加速器

### 2.1 主闭环（所有人每天走一遍）

```text
打开
 → 收昨日奖励 / 签到
 → 做 1～3 个今日任务（含步数）
 → 进度条前进（养成物/兑换进度）
 → 抽一次 或 看兑礼倒计时
 → （可选）邀好友加速 / 偷好友能量
 → 结束，明日提醒
```

### 2.2 四个加速器

| 加速器 | 玩法 | 目的 |
|--------|------|------|
| A 养成 | 种树/养宠物/点亮城市灯牌（三选一做深） | 日留、情感 |
| B 步数 | 微信运动兑换能量 | 零成本燃料 |
| C 社交 | 偷能量、组队、助力砍进度 | 唤活+裂变 |
| D 赌徒轻量 | 转盘/九宫格/次数夺宝 | 消耗积分、制造高潮 |

**第一期只做一个养成皮肤**（建议：能量罐 / 小宠物 / 许愿盒三选一），不要五条养成线并行。

## 3. 具体玩法设计（可直接研发）

### 3.1 每日打开：签到 + 定时宝箱

- **7 日循环签到**：奖励递增，第 3/5/7 天给抽奖次数或开盒钥匙  
- **早 8–10 点、晚 8–10 点** 两场「限量开兑/开抽」（学步数宝限时开闸）  
- 漏签：每月可用少量积分补 1–2 次，或看 1 次激励视频补签（非强制）  

目标：制造两个 DAU 高峰，而不是匀速无聊。

### 3.2 步数玩法

- 授权微信运动后，步数按档兑能量（如 3k/6k/1w）  
- 能量进养成进度，也可部分进抽奖次数  
- **不能只靠步数**：要配合签到与社交，否则被刷步设备打穿  

### 3.3 养成进度（公司付钱的“果园”）

用户养一个虚拟目标，进度满了兑 **真实低价礼**：

- 新用户首棵/首宠：**3–7 天可完成**（建立“真的能拿到”的信任）  
- 第二轮开始变慢，引导邀请、看广告、逛街加速  
- 加速任务：浏览商品 15s、加购、下单、邀新、组队  

**公司承担礼品综合成本**，所以：

- 首轮礼品综合成本建议压在 **5–12 元**  
- 月度发放量有总预算阀门，可后台熔断  

### 3.4 偷 / 助力 / 组队（学蚂蚁森林，服务唤活）

| 玩法 | 规则要点 |
|------|----------|
| 偷能量 | 好友间互偷，不损伤对方已锁定进度；主要用来叫人回访 |
| 助力砍进度 | 兑礼差最后 10% 时可邀人砍；每人每日可帮别人有限次；防同一小圈子刷 |
| 今日小队 | 2–4 人，全队任务达标共享奖励；差 1 人打开时强提醒 |

社交文案要「好玩」：  
「帮我点一下，我差最后一口粮」比「求助力」更适合年轻人。

### 3.5 抽奖 / 夺宝（消耗积分的高压泵）

- 任务与邀请产 **次数**，不是直接发高成本实物  
- 奖池公开：谢谢参与 / 积分 / 小礼 / 限定礼  
- 未中奖也要有反馈（积分返还一部分或进度+1），降低弃玩  
- 「积分夺宝」：多人投注次数，满员开奖（学步数宝幸运夺宝，**不用现金筹码**）  

### 3.6 兑礼门槛要“柔”（学步数宝精髓）

不要只做「攒满 10000 分换一个」。并行提供：

1. **纯能量/积分兑**（门槛高或库存少）  
2. **积分 + 邀请人数**（拉新）  
3. **积分 + 连续签到天数**（留存筛选）  
4. **积分 + 小额现金**（变现）  
5. **抽奖碰运气**（情绪）  

同一件 1688 小礼，可以用不同门槛入口放出，让货币真正流转起来。

## 4. 裂变设计（公司为自己拉新）

### 4.1 有效新用户

仅当同时满足才结算邀请奖：

1. 新设备/新账号首次进入  
2. 完成授权  
3. 完成签到或首个非分享任务  
4. 24h 内未命中风控  
5. 奖励冻结 24h 后到账  

### 4.2 裂变触发点（多触点，轻强度）

不要只做一个「邀请有礼」页。在路径中埋多个自然分享点：

- 养成进度 80%/95%  
- 抽奖中奖海报  
- 组队差 1 人  
- 限时开兑前  
- 兑换成功晒单  

每个用户每日主动邀请成功次数设上限，避免变传销感。

### 4.3 K 因子经营

```text
K = 人均有效邀请 × 新用户次日留存
```

- K < 0.2：先改玩法与首兑体验，禁止加大奖  
- K 0.3–0.6：健康冷启动  
- K > 1 且激励成本失控：立即降奖、加风控（可能是刷出来的）

## 5. 激励成本：钱是公司的，必须算死

### 5.1 综合成本公式

```text
单件激励综合成本 =
采购价 + 代发运费 + 包材 + 支付费 + 售后预提 + 客服摊销
```

1688 标价 1–10 元只是采购价，**运费后可能翻倍**。选品以综合成本决策。

### 5.2 预算纪律

| 规则 | 建议 |
|------|------|
| 月激励总预算 | ≤ 当月预计收入的 40%（冷启动可短期到 60%，但必须有截止日期） |
| 单 DAU 日均激励成本 | 早期目标区间自行标定后严格监控，超标自动降奖 |
| 首兑礼 | 快、真、便宜，专门买信任 |
| 大奖 | 限量、抽选、公示，不当作无限必得 |
| 熔断 | 日预算打满则当日大奖/开兑自动降级为积分奖 |

### 5.3 默认不做

- 可提现现金红包常态化  
- 无上限邀请必送贵价礼  
- 虚假库存、虚假中奖  
- 强制分享才能玩主流程

## 6. 变现：流量怎么变成公司收入

公司自营，变现顺序：

### 6.1 第一优先级：现金 + 积分商城

- 货盘：年轻人喜欢的低客单好物（饰品、数码配件、美妆小样、收纳、潮玩周边、零食小件等）  
- 支付：现金为主，积分抵 5%–10%  
- 与激励礼品可同供应链：激励款引流，商城款赚钱  
- 任务里「浏览/加购/下单得加速」把养成玩家导入购买  

### 6.2 第二优先级：IAA

- 激励视频换能量/补签/加抽次（可选）  
- 插屏/原生信息流（体验可接受范围内）  
- DAU 起来前不把广告当救命稻草，但代码与回调要预留  

### 6.3 第三优先级：品牌广告主

- 品牌买任务曝光、奖池冠名、商品植入  
- 这是「卖流量」，仍然是我们自营产品，不是给对方做业务系统  

### 6.4 回本判据

```text
贡献毛利 =
商城毛利 + 广告净收入 + 品牌费
− 激励综合成本 − 运费补贴 − 支付 − 售后 − 投放
```

连续 4 周贡献毛利为负且次留不升，必须降激励，而不是加投流。

## 7. 主题皮肤 ≠ 业务绑定

可按节日/热点换皮（校园季、春节、电竞周、宠物种草周），只换：

- 视觉与文案  
- 部分任务文案  
- 奖池里的限定款  

**不换**账户、积分、任务引擎、裂变、订单、风控。  
同袍会/汉服节/景区若出现，最多是某一期皮肤或广告主，**写进 campaign 配置，不写进产品定位。**

## 9. 后台 / 数据 / 接口原则

### 9.1 后台必有

任务、积分、养成进度规则、奖池库存、预算熔断、邀请与渠道、风控、履约、数据看板（DAU/留存/K/激励成本/毛利）

### 9.2 表与接口方向

围绕：`users`、`points_*`、`tasks_*`、`growth_progress`（养成）、`social_actions`（偷/助力）、`teams`、`lottery_*`、`prizes`、`fulfillments`、`products`、`orders`、`channels`、`budget_guards`、`risk_events`

接口必须服务端校验；积分幂等；库存事务；回调验签；全链路 `platform/channel/campaign/inviter`。

### 9.3 需求评审六问

1. 提升 DAU、次留、K、转化、毛利里的哪一项？  
2. 公司要多掏多少激励成本？预算从哪来？  
3. 是否可配置、可熔断？  
4. 首兑/反馈是否够快？  
5. 有无强制分享、提现、假奖？  
6. 下线某个主题皮肤后功能是否仍成立？  

答不上来不排期。

## 10. 风险与避坑（自营流量特别容易死在这）

1. **激励 > 收入**：玩成慈善机构  
2. **首兑太慢**：用户不信你会发货  
3. **首兑太猛 + 无风控**：被工作室薅穿  
4. **社交过载**：朋友圈臭了，K 短期高长期崩  
5. **提现诱惑**：黑产与合规双杀  
6. **功能大杂烩**：没有一条每日主闭环  
7. **和第三方业务缠在一起**：定位再次跑偏  
8. **只看注册不看次留与毛利**：虚假繁荣

## 11. 团队每周只盯的看板

1. DAU、DAU/MAU  
2. 次留、7 留  
3. 任务完成率、养成推进率  
4. 抽奖率、兑礼率、发货时效与客诉  
5. K、有效新增成本  
6. 单 DAU 激励成本、月激励/收入  
7. 商城毛利、广告 ARPDAU  
8. 刷量率  

每周必须输出：保留一个、优化一个、关掉一个。

## 12. 总纲金句（贴墙上）

1. **我们卖的是注意力和习惯，不是给谁做系统。**  
2. **公司的钱只买可回收的行为：打开、传播、停留、下单、看广告。**  
3. **向果园学信任，向砍一刀学进度，向步数宝学流转，向蚂蚁森林学唤活。**  
4. **礼品要真，成本要控，风控要硬，主路径要短。**  
5. **主题可换皮，引擎不换血；第三方永不写入产品灵魂。**
