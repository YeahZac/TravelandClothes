# 全民优享 · 能量罐 — 前端信息架构（V0.9）

> 依据：`自营流量产品增长变现总纲.md`  
> 工程：`全民优享/`（uni-app Vue3 + Vite，mock 数据）  
> 范围：只做前端可预览闭环，不接库/接口/COS

## 1. 对标取舍

| 学谁 | 落到本产品 |
|------|------------|
| 芭芭农场 / 多多果园 | 首页能量罐进度 + 首兑 3–7 天可完成 |
| 蚂蚁森林 | 好友偷能量、小队唤活 |
| 步数宝 | 步数分档兑能量、限时开兑、柔性兑礼门槛 |
| 砍一刀 | 「差一点点」文案与进度焦虑，次数封顶 |
| try try | 路径短：打开→签到→任务→抽/兑 |

刻意不做：可提现红包、强制分享、无限拉新送贵礼、文旅/汉服业务入口。

## 2. 每日主闭环（首页一屏）

```
打开 → 签到 → 看能量罐进度 → 做 1～3 个快任务
    → 抽一次 / 看晚场开兑 → （可选）偷能量/邀人 → 结束
```

## 4. 视觉方向

- 品牌名「全民优享」在首页首屏为英雄级信号；皮肤名「能量罐」为副标。
- 主色珊瑚 `#FF5C4A`，加速色薄荷 `#2EC4B6`，纸色 `#FFF7F2`。
- 轻游戏 / 潮玩感，非政务官网、非紫渐变模板风。
