## 0. 现状失败（V1 实装审计）

对照 `全民优享/src/pages/home/index.vue`、`energy/index.vue`、`mall/index.vue`、`festival/index.vue`、`mine/index.vue`、`App.vue`、`components/*`、`static/ui`、`static/tab`。

### 0.1 图标是同一模具，不是一套物件

`static/ui/ico-*.png` 全部是：圆角色块 + 白色圆环 + 一个小符号 + 左上角高光球。这是字母块的换代表现。`mock/data.js` 的 `quickEntries.icon` 仍是单字「签 / 抽 / 节 / 购 / 兑 / 邀」。

同一符号换色，入口无法分辨：

| 文件 | 实际图形 | 被当成 |
|---|---|---|
| `ico-chest.png` | 同心圆 + 高光球 | 宝箱 / 我的勋章 |
| `ico-wheel.png` | 同上，偏红 | 转盘 |
| `ico-rain.png` | 同上 | 能量雨 |
| `ico-quiz.png` | 同上，蓝色 | 问答 |

`ico-gift.png` 在 `mall/index.vue` 写死为每一个 SKU 封面。`ico-festival.png`（星星圆盘）同时出现在首页金刚、热门、Banner、能量罐热门、汉服节主视觉、每一张票封面。`battery.png` 与 `battery-72.png` 是同一张扁平电池。`coin.png` 无币文、无厚度，钱包、漂浮气泡、弹窗光晕、弹窗主图四处共用。`chest.png` 是扁平礼盒，和第 7 日语义、和 `ico-chest` 都不是同一件东西。`grid-tile.png` 是一块纯色。

底栏是另一套语言：`static/tab/*.png` 为灰色细线（房子、公文包、五角星、电池框、人）。页面里是糖果圆盘。两套不能共存。

### 0.2 模块贴死，骨架五页一份

首页 `.sheet` 的 `gap` 是 24rpx（12px）。Banner 与 sheet 间距 8rpx。签到、金刚、晚场条、热门、公告是同一张白底上的连续块，画布颜色露不出来。

汉服节、我的的 sheet `gap` 为 20rpx。商城 Banner 下按钮 `margin-bottom: 16rpx`。能量罐热门宫格与任务卡间距 24rpx。

首页、能量罐、汉服节、我的共用同一模板：蓝渐变顶（`#9EC4FF → #EEF5FF`）+ 白 sheet 顶圆角 36rpx + 同样的蓝调阴影 `rgba(26,79,212,.08)` + 圆角 24rpx 白卡片。换的是文案，不是构图。

首页入口重复三次：Banner、6 个同构金刚（`quickEntries`）、2×2 热门，抽奖 / 汉服节 / 商城 / 能量在 Tab 之外又各出现多遍。

### 0.3 层级被字重和彩虹拉平

标题、按钮、标签、价格大量使用 700–800。32 / 30 / 28 / 26rpx 挤在一起，没有「数字级」。

Banner 三帧是橙、蓝、薄荷三套渐变，右边再贴一个圆盘。步数区薄荷绿，价格 `#FF4D4D`，弹窗底 `#FFF6E4` 蜜桃渐变上叠两张同一枚金币，按钮还有橙 / 蓝 / 薄荷三套厚底糖。`App.vue` 把「拒绝软粉」写进注释，`RewardPopup.vue` 仍是蜜桃渐变。

能量英雄：扁平电池贴图居中，`percent` 画在罐子下面，液体高度不随进度变化，三枚空白金币在漂。参考板里的充电页是玻璃圆柱立在椭圆舞台上，百分比写在液体里。

## 1. 设计命题与反目标

**命题：** 全民优享是一台白天打开的充能机——全 App 只有能量罐这一只玻璃英雄，奖励靠有币文的金属金币和一颗橙色主按钮说话；五张主页面五套骨架，模块之间必须露出画布。

反目标（出现即返工）：

1. **禁止字母块图标。** 禁止色块上放一个汉字、一个对号、一颗星、一个同心圆。底栏、金刚、任务、勋章、嘉宾头像全部算在内。
2. **禁止 `ico-gift` 到处复用。** 商城 SKU、票封面、Banner、弹窗、第 7 日宝箱必须是不同文件。商城 / 礼品 / 汉服节三套图禁止互为替身。
3. **禁止卡片贴卡片。** 兄弟模块之间必须露出 ≥24px（48rpx）画布。禁止「蓝顶 + 白 sheet + 一串相同白卡片」五页复制。
4. **禁止软 AI 蜜桃色。** 禁止 `#FFF6E4` / 桃粉渐变面板、禁止每个卡片一种彩虹渐变、禁止高光球圆盘当图标、禁止 emoji 当插画。

另外三条一起禁：

- 提现红包不做主路径。参考板 2、3、4 里的「开 / 0.51 元 / 0.66 元 / 3.68 元 / 天天领话费 / 超级红包雨 100 万」只保留「一个主角物件 + 一个大数字 + 一颗主按钮」的弹窗语法，金额单位改成能量、积分或抽次。
- 禁止全页都在漂、都在跳。动效名额见 §8.9。
- 禁止把汉服节红、商城蓝、能量绿做成三套主题皮肤贴在同一骨架上。

## 2. 受众审美：2026 年轻人觉得贵，和觉得廉价

对象：16–28 岁，每天打开网赚 / 养成 / 电商小程序的人。他们分得出「参考板里的充电罐」和「用圆盘模仿充电罐」。

觉得贵的，本产品要落到画面上的：

| 信号 | 落到全民优享 |
|---|---|
| 一件说得清的材料 | 玻璃罐 + 金属金币。光从左上来，接触阴影落在舞台上。全 App 不引入第二套材料（不要再加粘土、霓虹、玻璃拟态卡片） |
| 数字像账，不像贴纸 | 等宽数字，单位写在旁边（能量、步、%）。余额用墨色，增量才用橙色 |
| 模块之间有空气 | 个人中心参考板的留白是标尺。一张屏幕上同时「响」的主按钮只有一颗 |
| 图是这件东西本身 | 商城用商品照片；票用票面插画；罐子用会随进度升降的液体 |
| 文案具体 | 「再充一点就能兑」「晚场 20:00–22:00」。不用「百万金币等你拿」「超级奖励」 |
| 底栏安静 | 线性图标，选中只变一处颜色。内容区比底栏响 |

觉得廉价、本版要清掉的：

- 每张卡一种渐变，六个入口六个颜色。
- 同一张礼物图盖住所有商品。
- 按钮全部做成厚糖块，每一行任务都是一颗蓝按钮。
- 蜜桃 / 浅粉大面板、emoji、字母圆头像。
- 百分比写在主体外面，主体是一张不会变化的贴图。
- 入口重复：同一目的地同时占据 Banner、金刚、宫格和底栏，用户会判断成填充位。

从五张参考板只取这些 DNA：

1. **总览板：** 天空只做舞台；英雄是一只立在椭圆台上的圆柱，百分比在物体上；漂浮的是有面文的金币；功能图标是互不相同的立体小物件，带自己的微标签。
2. **弹窗板：** 一窗一物、一个大数字、一颗主按钮、深色遮罩。红包金额语法整段丢弃。可保留的二级形态：转盘结果、宝箱打开、奖品格（能量 / 实物，不出现人民币「开」）。
3. **赚现金板：** 签到是一排金币而不是数字圆点；任务行是「独特左图 + 标题与进度 + 右侧小按钮」；Banner 是完整场景（卫星、宝箱、食物、火箭占画面右侧约 40%），不是渐变色块上贴枚图标。现金与红包雨文案不搬。
4. **分活动板：** 每个活动是一套构图。充电页是能量罐的直接原型（圆柱、台上、百分比在罐体、金币环绕、下方热门是插画卡片）。喝水页的草地吉祥物、话费页的全红信封、猜谜页的棋盘，不搬进本产品——我们没有第二只吉祥物。
5. **个人中心板：** 大留白、一枚带翅金属勋章、两项大数字、两行细菜单、底部一条小插画。这是「我的」的骨架，不是能量页的缩小版。

## 3. 色彩

原则：一页只允许一个强调色在「响」。橙色是行动，金色是货币，绿色只活在罐内液体和步数数字里，朱红只活在汉服节，蓝色只活在链接与底栏选中。

### 3.1 色板

| Token | Hex | 用途 |
|---|---|---|
| `ink` | `#121826` | 标题、余额数字、正文强调 |
| `body` | `#3A4252` | 正文 |
| `mute` | `#5E6977` | 辅助、单位、已完成。禁止用更浅的灰做 22rpx 以下文字 |
| `line` | `#E6E8EE` | 分割线、描边、售罄底 |
| `canvas` | `#F4F6F8` | 首页下半、商城、我的的页面底 |
| `paper` | `#FFFFFF` | 卡片、弹窗、底栏 |
| `festival-paper` | `#F6F1EA` | 仅汉服节主视觉以下的页面底 |
| `sky-0` | `#8EBEFF` | 仅能量罐舞台顶端 |
| `sky-1` | `#D7E8FF` | 舞台中段 |
| `orange` | `#F06400` | 主按钮填充下沿 |
| `orange-hot` | `#FF8A2A` | 主按钮填充上沿 |
| `orange-depth` | `#C44800` | 主按钮厚度 |
| `orange-text` | `#E25A00` | 奖励增量、价格以外的「+能量」文字。最小 24rpx / 700 |
| `gold` | `#F5B942` | 金币、第 7 日宝箱高光 |
| `gold-deep` | `#C8880A` | 金币描边、连签标签 |
| `liquid` | `#1FBF73` → `#8EF0C0` | 只填在玻璃罐内部，自下而上 |
| `link` | `#245BDB` | 文字链、底栏选中（汉服节除外） |
| `cinnabar` | `#C23A2A` | 汉服节印章、汉服节底栏选中、票务强调 |
| `cinnabar-text` | `#B42318` | 汉服节页上的强调文字，最小 24rpx |

| `hero-scrim` | `rgba(12,18,32,.45)` → 透明 | Banner / 汉服节标题压字 |

### 3.2 使用规则

- 橙色按钮同时出现的上限：一屏一颗填充橙按钮。其余行动用描边或文字链。任务行里只有「领取」用填充橙，「去完成」用描边。
- 绿色不铺底。步数条允许一条 8rpx 高的 `liquid` 进度，数字用 `ink`。禁止现在的 `#E8FFF4` 大绿块。
- 商城价格用 `ink`，划线价用 `mute`。折扣标签才用 `cinnabar` 小标签，一张卡一个标签。
- 禁止：薄荷页、桃粉页、紫圆盘、每帧 Banner 换一个色相、蓝调投影罩在所有白卡片上。
- 白卡片阴影统一中性：`0 8rpx 24rpx rgba(18,24,38,.06)`。蓝色投影 `rgba(47,107,255,.18)` 只允许出现在能量罐舞台的罐子下方。
- 文字橙色、朱红不得小于 24rpx。20rpx 及以下只用 `ink` / `body` / `mute`。
- 主按钮上的文字是白色。橙色小字直接放在白底上时用 `orange-text`，不用 `#FF7A1A`（对比不够）。

## 4. 字体

家族：`PingFang SC`，数字 `font-variant-numeric: tabular-nums`。

| 角色 | 尺寸 | 字重 | 行高 | 用在 |
|---|---|---|---|---|
| 数字 Display | 64rpx | 700 | 1.0 | 罐内百分比、我的三项主数字、弹窗奖励数字 |
| 数字 L | 48rpx | 700 | 1.05 | 步数、弹窗次级数字 |
| 页面标题 | 40rpx | 700 | 1.2 | 导航标题、汉服节主标题 |
| 区块标题 | 32rpx | 600 | 1.25 | 签到、今日任务、官方票务 |
| 卡片标题 | 28rpx | 600 | 1.3 | 任务名、商品名、票名 |
| 正文 | 26rpx | 400 | 1.5 | 公告摘要、活动介绍 |
| 按钮 | 28rpx | 600 | 1.0 | 主按钮。行内按钮降到 24rpx / 600 |
| 辅助 | 22rpx | 400 | 1.35 | 单位、库存、时间 |
| 微标 | 20rpx | 500 | 1.2 | 标签、金刚文字、底栏文字 |

字重规则：

- 700 只给数字和页面标题。
- 600 给区块标题、卡片标题、按钮。
- 400 给正文和辅助。
- 禁止 800。禁止一行里标题和辅助都加粗。
- 一个区块里最大的字只有一个：要么是数字，要么是标题。

## 5. 间距

基数 8px。模块与模块是硬下限，组件内部可以更紧。

| Token | px | rpx | 用在 |
|---|---|---|---|
| s1 | 4 | 8 | 图标与微标、标题与辅助的最小距离 |
| s2 | 8 | 16 | 行内元素间隙、标签与标题 |
| s3 | 12 | 24 | 卡片内标题到内容、任务行上下内边距 |
| s4 | 16 | 32 | 页面左右页边距、卡片内边距 |
| s5 | 24 | 48 | **兄弟模块之间的下限。** 必须露出 `canvas` 或 `festival-paper` |
| s6 | 32 | 64 | 英雄区结束到第一个模块；我的头像区到菜单 |
| s7 | 48 | 96 | 页底安全区以上的收尾留白（不含 safe-area） |

硬规则：

- 页面左右页边距固定 32rpx。Banner、签到条、票、商品栅格都在这个宽度里。汉服节主视觉除外，主视觉全出血。
- **兄弟模块间距 ≥ 48rpx。** 签到条、金刚、晚场条、任务、公告、商品栅格、票栈，两两之间都算兄弟模块。现在的 24rpx / 20rpx / 16rpx / 8rpx 全部不合格。
- 同一模块内部的格子可以更紧：金刚项间距 16rpx，商品栅格间距 16rpx（8px），任务行靠 1rpx `line` 分隔，不靠各自再包一张卡。
- 禁止卡片套卡片。任务列表不要外面再包 `yx-card`。公告不要白卡片，直接铺在画布上。
- 分组菜单（我的）每组是一张卡，组与组之间 48rpx，组内行距靠分割线，行高 104rpx。
- 底栏高度 100rpx + 安全区。内容最后一块距离底栏至少 48rpx。

## 6. 图标

### 6.1 一个家族

家族名：**Gloss Object**。每枚都是独立小物件，顶左主光，底部接触阴影，透明底。

允许的材料只有两种：磨砂塑料（功能入口）和金属（金币、勋章）。

禁止：

- 圆角色块 + 白圆环 + 高光球这一模具。
- 汉字、字母、emoji 充当图标。
- 把同一 PNG 改色再导出。
- 线框底栏和立体金刚混用两套风格。底栏是同一家族的简化正视图（见 6.4），不是另一套开源线性图标。
